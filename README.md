# Ginie downloads

Official macOS and Windows installers for Ginie. This repository contains binaries,
checksums and support information, with no application source code.

Visit [the Ginie website](https://ginie-web-eight.vercel.app) for downloads and the full
first-use guide. Get verified installers from [Releases](https://github.com/tohin003/ginie-releases/releases).

The current distribution is a preview. macOS installers are ad-hoc signed, not
notarized. Windows installers are unsigned. Operating-system security warnings
may appear. SHA256SUMS.txt is supplied with each release.

Capture exclusion depends on your operating system and sharing software. Test
your actual share preview before relying on it. macOS focus lock is Mac-only.

For help, [open an issue](https://github.com/tohin003/ginie-releases/issues).
Do not include screenshots with personal information, credentials, cookies or
private conversations. Describe your OS, Ginie version, and the steps that failed.

Third-party components retain their own licenses. Earlier source licenses are
unaffected by the current proprietary distribution.
